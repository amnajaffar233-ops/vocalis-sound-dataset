# Vocalis Dataset Sources

## Project Overview
Vocalis is an AI-based sound classification and automated response system. This document records the audio datasets evaluated or selected for the project.

## 1. ESC-50 Dataset

- **Dataset Name:** ESC-50
- **Source:** https://github.com/karolpiczak/ESC-50
- **Type:** Environmental sound classification
- **Format:** WAV audio files
- **Purpose:** To explore environmental sounds for Vocalis model development.
- **License:** CC BY-NC 3.0, as specified by the dataset authors.

## 2. Planned Sound Categories

The project aims to investigate the following sound categories:

- Alarm
- Dog barking
- Cat sounds
- Car horn
- Clapping
- Rain
- Speech
- Glass breaking

Category availability will be checked against each dataset before use.

## 3. Dataset Evaluation

Each dataset will be reviewed for:
- Relevant sound categories
- Audio quality and format
- Number of audio samples
- Licensing and usage conditions
- Suitability for machine learning

## 4. Data Management

Original audio files will be stored locally or in suitable dataset storage. GitHub will contain dataset documentation, metadata, and preprocessing code rather than large audio collections.

## 5. Current Status

Dataset sources are being reviewed. Final dataset selection and category coverage will be documented after verification.
