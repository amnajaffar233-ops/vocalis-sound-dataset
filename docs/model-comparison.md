# Vocalis Model Comparison

## 1. Overview
Vocalis is an AI-based sound classification and automated
response system. Three machine learning models were evaluated
using Jupyter Notebook experiments.

## 2. Models Evaluated
- Support Vector Machine (SVM)
- Random Forest
- Convolutional Neural Network (CNN)

## 3. Initial Accuracy Results

| Model | Accuracy |
|---|---:|
| SVM | 27% |
| Random Forest | 94.58% |
| CNN | 51% |

## 4. Results Analysis
Random Forest achieved the highest observed accuracy of 94.58%
among the three evaluated models.

CNN achieved 51% accuracy, while SVM achieved 27% accuracy
in the current experiments.

These results indicate that Random Forest is the strongest
candidate among the evaluated models so far.
