# Vocalis Sound Dataset

## Purpose
This folder contains information about the audio datasets used in Vocalis.

## Sound Categories
- Alarm
- Dog Barking
- Cat Sounds
- Car Horn
- Clapping
- Rain
- Speech
- Glass Breaking

## Dataset Preparation
1. Collect audio files from suitable datasets.
2. Organize sounds by category.
3. Check audio format and quality.
4. Preprocess audio for machine learning.
5. Prepare data for model training and testing.

## Note
Large dataset files are stored separately and are not uploaded directly to GitHub.
